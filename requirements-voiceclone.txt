# Dependencies for cloners.py / generate_all.py / Tester.py
# ==========================================================
# Installed and verified 2026-09-02 in conda env "voiceclone"
# (E:\envs\voiceclone, ~6.7 GB, 175 packages). Note this machine's conda
# writes envs to E:\envs, not C:.
#
#     conda create -n voiceclone -y python=3.10
#     conda activate voiceclone
#     pip install -c constraints.txt -r requirements-voiceclone.txt
#
# THIS IS A SEPARATE ENV FROM "voicefake" (see requirements.txt) AND MUST
# STAY THAT WAY. The two stacks pin incompatible versions:
#
#                voicefake (detectors)   voiceclone (cloners)
#   torch        2.6.0+cu124             2.3.1+cu121
#   numpy        2.2.6                   1.26.4   (torch 2.3 predates numpy 2)
#
# The two halves talk through .wav files on disk, not in memory:
#   generate_all.py  (voiceclone) -> D:\results and benchmarks\generators\
#   score_all.py     (voicefake)  -> D:\results and benchmarks\discriminator\
#
# ---------------------------------------------------------------------------
# FOUR TRAPS, all hit during setup. Install with the constraints file.
# ---------------------------------------------------------------------------
# 1. `lightning` and `x-transformers` declare a bare `torch` dependency and
#    will happily REPLACE torch 2.3.1+cu121 with the latest CPU-only wheel
#    from PyPI, silently killing CUDA. Always install with
#    `-c constraints.txt` (below) and re-check torch.cuda.is_available()
#    after any pip install into this env.
#
# 2. `lightning` IS required, despite not looking like it. CosyVoice2's
#    flow_matching imports matcha.utils.pylogger, which imports
#    lightning.pytorch.utilities.rank_zero_only -- for a logging decorator.
#    Installed with --no-deps here so it cannot touch torch.
#
# 3. setuptools >= 81 removed `pkg_resources`, which lightning-utilities
#    still imports. Hence the setuptools pin.
#
# 4. `x-transformers` is NOT needed: it is only used by the DiT flow, and
#    CosyVoice2's cosyvoice2.yaml uses CausalConditionalDecoder. Left out.
#
# Also required outside pip, downloaded on first use:
#   - NLTK data for g2p_en (MeloTTS English):
#       python -c "import nltk; [nltk.download(p) for p in
#         ['averaged_perceptron_tagger_eng','cmudict','punkt','punkt_tab']]"
#   - MeloTTS base-speaker checkpoints and BERT models (from HuggingFace)
#   - whisper 'base' weights for Tester.py's WER (~139 MB)
#   NO ffmpeg needed: Tester.py decodes with librosa and hands whisper an
#   array, bypassing whisper's ffmpeg-based loader.
